Sources: FanGraphs team dashboard (bat + pit + fielding: WAR, wRC+, BsR/wBsR, xwOBA, xFIP, SIERA, OAA), MLB Stats API schedule, ESPN scoreboard moneylines (DraftKings), and Kalshi Game Winner volumes. Model fair odds use grouped z-factors (offense / pitching averaged, then WAR+OAA half-weight) mapped to an expected run delta and a logistic (τ=2.0). Overall Edge remains the raw z-sum for ranking. Market odds are multiplicatively de-vigged so both sides sum to 100%. Value is model win% minus de-vigged market win% on the best side. Money shows Kalshi dollar volume per team and the ratio vs the other side (no highlight under 2×, yellow for 2.0–4.99×, red for 5.0×+). Money volumes re-fetch live from Kalshi on every page load in Live mode. Historical locks each game ~45 minutes before first pitch (edges + market + money), keeping last-known 4casters/ESPN odds if the live book is already gone, then grades Finals. Edge-system P&L: Val side 1u ML (+ optional 1u spread in −150…+110, prefer ±1.5). Stake: +odds risk $100; −odds risk |price| to win $100.
